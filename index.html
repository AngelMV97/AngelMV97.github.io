01

WOBBLEHEADS (Game Jam)

A team-developed 3D multiplayer party game created during a game jam using Unity and Blender. Players engage in fast-paced arena battles where insults act as projectiles that progressively enlarge opponents' heads. As heads grow, characters become increasingly unstable, making movement and positioning more challenging until the head eventually bursts.

The game combines physics-inspired movement, lighthearted combat, and a stylized low-poly city environment to create a chaotic and comedic competitive experience centered around the game jam theme, "Toxic."

Technologies: Unity, C#, Blender

3D Environment Design (WOBBLEHEADS)

Designed, modeled, and optimized the complete playable environment for WOBBLEHEADS as part of a multidisciplinary game jam team, covering the entire environment production pipeline from blockout and level layout to modular asset creation, material setup, optimization, and Unity integration.

The environment represents a stylized urban intersection featuring multiple combat platforms connected by pedestrian crossings, surrounded by buildings, vegetation, and urban props.

Technologies: Blender, Unity, Low-poly Modeling, UV Mapping

03

Cattle Herding

Custom gameplay implementation built with assets from Unity Learn's Basic Gameplay mission. Rather than recreating the tutorial, I developed an original 2-player cattle herding mechanic where players compete to guide wandering animals into a corral by launching herding dogs.

This project allowed me to practice Unity's Input System, collision handling, UI management game state control with Singleton managers, and balancing gameplay mechanics for multiplayer.

Technologies: Unity, C#, Input System, UI System

04

Plane Programming

Extended the original Unity Learn challenge by implementing additional gameplay systems, UI feedback, and physics improvements beyond the tutorial requirements. The objective is to pilot an aircraft through an obstacle course while maintaining controlled flight.

Beyond the original challenge, I implemented several gameplay and polish improvements, including a Game Over UI, collectible items, automatic pitch stabilization when no input is provided, and a physics-based crash effect that applies torque to create a more realistic nosedive after colliding with obstacles.

Technologies: Unity 6, C#, Rigidbody Physics, Input System
